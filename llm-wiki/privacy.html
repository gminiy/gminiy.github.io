개인정보처리방침

시행일: 2026-10-27

1. 목적과 사용자

llm-wiki-email-aggregate(이하 "이 도구")는 운영자 본인이 소유한 Gmail 계정의 메일을 본인 컴퓨터에 보관하기 위한 개인용 도구입니다. 운영자 외의 사용자에게 제공하지 않습니다.

2. 접근하는 정보

이 도구는 Google OAuth의 https://www.googleapis.com/auth/gmail.readonly 권한만 요청하며, 운영자가 지정한 메일의 원문과 첨부파일, 메일 계정 주소를 읽습니다. 메일을 보내거나 수정·삭제하지 않습니다.

3. 저장과 처리

읽은 메일과 인증 토큰은 운영자의 컴퓨터에만 저장됩니다. 이 도구는 별도의 서버를 운영하지 않으며, 데이터를 운영자 외의 제3자에게 판매·공유·전송하지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

이 도구가 Google API로부터 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

5. 접근 권한 철회와 삭제

운영자는 Google 계정의 서드파티 액세스 설정에서 언제든 권한을 철회할 수 있으며, 본인 컴퓨터의 저장 데이터와 토큰 파일을 삭제할 수 있습니다.
